Resumen Estructurado (Abstract)

Se presenta una aproximación computacional fundamentada en geometrías moleculares 3D embebidas en espacios hiperbólicos. Mediante cribado virtual ultra-masivo sobre la diana proteica NS5B, se logró identificar tres candidatos antivirales de alta afinidad (Kd < 12 nM).
